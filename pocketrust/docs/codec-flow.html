compress

Compresses one input packet i_t. The first half updates the encoder model: the mask M, the build vector B, the ring of change vectors D and the new_mask history P. The second half writes the packet fields in the same order that decompress_internal reads them. Nothing in compress can fail.

  • write h_twrites to the bitstream
  • send_maskset by the caller for this packet

Caller inputs

i_t
The input packet, F bits in 64-bit blocks.
R
Robustness level. X_t covers the changes of the last R + 1 packets, so the decoder can miss up to R of them.
new_mask
Rebuild M from B on this packet instead of only growing it.
send_mask
Send the full mask in q_t. Also clears d_t.
uncompressed
Send i_t raw with r_t = 1 and the count of F. Also clears d_t.

Encoder state

I
The previous input packet.
M
The mask of unpredictable bits.
B
Build vector: bits that changed since the last mask rebuild.
D, d_zero
Ring of the last 8 mask change vectors, and whether each one is zero.
num_d_zeros
Run of zero D rows that have already left the ring. Extends C_t past 8 packets.
P
Ring of the last 16 new_mask flags, used for c_t.

decompress

Wraps decompress_internal with the trust layer. While F is unknown it first looks for a reference packet that carries F. Once a packet parses, it decides from the history ring and the parse flags whether to trust the packet, and commits self.i and self.m only when it does.

  • decompress_internal() ↗jumps to the decompress_internal chart
  • mask_inc_wholeflag set by decompress_internal()
  • GuaranteedUnguaranteedverdict returned to the caller

History ring

0x00
Accepted packet. The only entry vt_gap_ok looks for.
0x01
Rejected or undecodable packet, pushed by decompress() or notify_packet_undecodable().
0x02
Lost packet, pushed once per packet by notify_packet_loss(n).
size
16 entries, which covers the largest window: v_t is 4 bits, so vt + 1 is at most 16.

decompress_internal

Reads one packet's fields in bitstream order, predicts the new mask M_t, and fills i_out. It stages M_t in scratch.m_delta and never writes self.i or self.m. decompress() reads the flags it sets and decides whether to commit.

  • read can fail and return None: it runs past num_bits or hits a malformed COUNT
  • mask_inc_wholeflag read by decompress()
  • return Noneexplicit validity check failed

What decompress() gets back

Some(DecodeFlags)
vt and rt for the accept rules, and next_pos / next_idx, the bit position right after this packet.
mask_inc_whole
The full mask that was sent differs from the predicted M_t somewhere.
mask_inc_changed
The full mask and the prediction differ on at least one bit in X_t.
count_f_mismatch
The F in a raw packet does not match the known F.
scratch.m_delta, i_out
Staged M_t and the decoded packet. These are copied into the state only if the packet is accepted.
